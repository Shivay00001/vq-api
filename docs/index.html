VisionQuantech API

https://api.visionquantech.com · One key for finance calculators, dev tools, image & PDF processing.

Quickstart

# 1. Health (no key needed)
curl https://api.visionquantech.com/health

# 2. Get a key from your VisionQuantech dashboard, then:
curl -X POST https://api.visionquantech.com/v1/calc/gst-interest \
  -H "Authorization: Bearer vq_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"type":"delayed","amount":100000,"due_date":"2026-08-20","pay_date":"2026-09-19"}'

# → {"tool":"gst-interest","rate_pct":18,"days_delayed":30,
#    "interest":1479.45,"late_fee":1500,"total":2979.45,...}

Auth

Send the key in the Authorization: Bearer header only — keys in URLs are rejected. Test keys start with vq_test_.

Idempotency

POSTs accept Idempotency-Key (8–128 chars). Same key + same body within 24h replays the stored response — safe retries, no double billing.

Errors

Every error is {"error":{"code":"…","message":"…","request_id":"…"} }. Codes: invalid_param (400), missing_auth/invalid_key (401), quota_exceeded (402), revoked_key/forbidden (403), idempotency_conflict (409), file_too_large (413), rate_limited (429 + Retry-After).

SDKs

# Python
import requests
h = {"Authorization": "Bearer vq_live_YOUR_KEY"}
r = requests.post("https://api.visionquantech.com/v1/calc/emi", json={
  "principal": 5000000, "annual_rate_pct": 8.5, "months": 240}, headers=h)
print(r.json()["emi"])

// JavaScript
const r = await fetch("https://api.visionquantech.com/v1/calc/emi", {
  method: "POST",
  headers: { "Authorization": "Bearer vq_live_YOUR_KEY", "Content-Type": "application/json" },
  body: JSON.stringify({ principal: 5000000, annual_rate_pct: 8.5, months: 240 })
});
console.log((await r.json()).emi);
